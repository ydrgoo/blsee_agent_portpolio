# 번들 글꼴 안내

스마트에디터 글꼴 메뉴와 같은 네이버 글꼴을 인포그래픽 HTML 렌더용으로 포함합니다.
**기본서체**는 시스템 글꼴이라 파일이 없습니다.

## 라이선스

모두 네이버(및 네이버 문화재단) 저작의 무료 글꼴이며, **SIL Open Font License 1.1**과 동일한 조건으로
소프트웨어에 번들·재배포할 수 있습니다. 글꼴 파일만 따로 유료 판매하는 것은 금지됩니다.
전문은 `OFL.txt`를 보세요.

참고: [네이버 나눔글꼴 라이선스 안내](https://help.naver.com/service/30016/contents/18088?lang=ko)
